## TA Management Portal


The project aims to provide an efficient, user-friendly platform for managing TA-related activities.

## 🚀 Features

- 👨‍💼 **Admin Dashboard** – Manage applicants, faculty information, and TA-related activities.
- 👨‍🏫 **Faculty Dashboard** – Access and manage TA applications.
- 📋 **Applicant Shortlisting** – Organize and review shortlisted candidates.
- 🔍 **Search & Filtering** – Quickly search applicant records.
- 🔐 **Role-Based Authentication** – Separate access for administrators and faculty.
- 📱 **Responsive Design** – Compatible with desktop, tablet, and mobile devices.
- 👤 **Personalized Dashboard** – Dynamic greetings and user-specific information.
- 📌 **Sticky Navigation Bar** – Easy navigation throughout the dashboard.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/Riyad1509/TA-UGA-Application.git
```

**2. Move the project**

Copy the project folder into the XAMPP `htdocs` directory.

**3. Start the server**

Open XAMPP Control Panel and start:

- Apache
- MySQL

**4. Configure the database**

- Open `http://localhost/phpmyadmin`
- Create the required MySQL database.
- Import the project's SQL file if available.
- Update the backend database connection settings.

**5. Run the project**

Open your browser and visit:

```text
http://localhost/TA_PORTAL/landing.html
```
